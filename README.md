# PixelPilot

Static website for PixelPilot's drone-based aerial imaging and inspection services.

## Services presented

- Aerial inspection of sites and infrastructure.
- Orthophoto and cadastral surveying.
- 3D digital terrain and object models.
- 360-degree aerial panoramas.
- Event and property filming from the air.

The public-facing content is in Russian and is designed as a service landing site with portfolio, company information, and contact sections.

## Tech stack

- Static HTML5
- CSS and JavaScript assets
- Bootstrap-compatible/Mobirise component bundle
- Image and icon assets stored in `assets/`

## Run locally

No build step is required. Serve the repository root with any static file server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Project structure

- `index.html` — main landing page.
- `assets/` — styles, scripts, fonts, icons, and media.
- Additional HTML pages — supporting service and contact content where present.
